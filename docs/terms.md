# Personal and private test use

Strident is a local assistant with administrator-controlled access. The administrator can operate approved host tools; member accounts can request writing and explanations. AI output can be inaccurate. Check important facts, code, legal statements and customer-facing claims before relying on or publishing them.

Use only files, accounts and services you are authorized to access. Do not use this installation to obtain another person's data, attack systems or evade access controls. Keep credentials private. The administrator may revoke access or stop the local service.

A successful model response does not prove that an action happened. Consult the task's tool evidence. Cancellation stops further worker activity but does not undo completed actions. A retry can repeat actions and requires review.
