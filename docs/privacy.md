# Strident personal and private test privacy notice

Effective October 22, 2026. This notice describes the supplied local application, not a publicly operated subscription service.

Strident stores usernames, salted password hashes, session records, task prompts, replies, tool evidence, history and saved memory on the computer running it. Member task data is held in separate account folders. The computer owner can access local files and must protect the operating-system account and disk. Storage is not encrypted by this application. Use operating-system disk encryption and appropriate file permissions.

The browser uses one necessary HttpOnly session cookie, expiring after eight hours. Logout revokes that session. No optional analytics, advertising pixels or marketing cookies are installed. Global Privacy Control does not activate tracking. No personal data is sold or shared for advertising by this code.

Model requests go to the configured local Ollama endpoint. Administrator web tools send requested URLs or search terms to the relevant websites or search provider. Optional Gumroad and Tailscale use their respective services when configured. Member writing sessions have no host tools or file attachments. They share the local inference process, not another member's application history. Infrastructure-level isolation of model timing/resources is not provided.

Tasks and memory remain until removed by the operator or account deletion. Member account deletion stops its task worker and removes its account, sessions and member data folder. It does not erase previously downloaded transcripts, operator backups or third-party logs. Deleted accounts must be removed again after restoring an old backup. Administrator data removal is an operator procedure, not a member action.

The private operator creates accounts and handles password recovery locally. No email addresses, payment details or telephone numbers are required. There is no public signup or email verification service. Contact the person who gave you access for account assistance. Do not submit confidential third-party information without authorization.

Before public service launch, the operator must publish their real identity, contact channel, applicable legal bases, retention schedule, rights process, subprocessors and international-transfer details based on the actual deployment. This local notice does not establish GDPR, CCPA or app-store compliance.
