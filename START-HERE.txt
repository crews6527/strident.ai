STRIDENT.AI 3.3.4 REPAIRED PRIVATE TEST BUILD

1. Extract the ZIP completely into a new folder. Keep the old copy as a backup.
2. Run Install-Strident.cmd (Python 3.12 is required).
3. Run Launch-Strident.cmd. The desktop window must show build 3.3.4.
   Enter Help, then open Settings, refresh models, select the exact installed
   task/writing model and save. With Ollama running, enter /testmodel.
   A completed reply is required to verify generation on this computer.
   Then run Live-Test.cmd to open an isolated browser test installation.
4. Expand First administrator setup in the browser. The launch window shows
   the setup key; the browser opened by the launcher fills it for you.
5. Choose your administrator username and a password of 15+ characters.
6. Run Help. Create a user account under Create user account. Log out, then
   use User login to verify its separate task history. Both login buttons
   authenticate against the same server; stored account role controls access.
7. As administrator, open Settings, choose your exact installed Ollama model,
   save and press Test saved model. Ollama must be running on this computer.

No default passwords, test accounts, model files or private data are included.
The isolated test keeps data in .live-test and leaves personal agent data alone.

To update your existing personal installation, close Strident and use
Apply-Strident-Update.cmd. Select the OLD installation folder. The updater
backs up source and verifies the replacement. Create the personal administrator
with Setup-Admin.cmd, then use Live-Preview.cmd or the desktop preview button.
Recreate the shortcut with Create-Desktop-Shortcut.cmd if it still opens an old
copy. The running window must identify version 3.3.4 and the expected folder.
